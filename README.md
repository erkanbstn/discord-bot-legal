# Discord bot yasal metinler

Discord bot uygulamalarının kullanım koşulları ve gizlilik metinlerini tutan depo.

## Ne var

Metinler bu deponun kökündedir. Uygulama kodu burada değildir.

## Çalıştırma

Dosyalar düz metin olarak okunur. Kurulum adımı yoktur.

## Yığın

Belge deposu. Çalışan bir uygulama içermez.
